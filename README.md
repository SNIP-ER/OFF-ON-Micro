# OFF-ON-Micro

Push-to-talk: микрофон включён только пока зажата кнопка.

Живёт в трее: иконка меняется (зелёная - микрофон включён, серая - выключен), правый клик по иконке -> "Закрыть".

# Настройка

`$micro = "..."` - в кавычках пишется название микрофона

`$PttKey = ...` - после равно пишется клавиша, при нажатии на которую активируется микрофон **(в 16-ом коде)**

`$VkShift = ...` - доп кнопка, которую нужно зажать для завершения скрипта **(в 16-ом коде)**

# Запуск скрипта
ПКМ по файлу скрипта -> Выполнить с помощью PowerShell

# Завершение скрипта
Для завершения скрипты нужно, при **зажатой** кнопки *(указанной в `$VkShift`)*, **нажать** на кнопку *(указанной в `$PttKey`)*
